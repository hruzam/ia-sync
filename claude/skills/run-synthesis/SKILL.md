# Run shape: synthesis-run (Oraculum-shaped)

**The one rule:** name this shape at kickoff and hold it for the duration.
Mid-run shape switches pay maximum context re-establishment cost for minimum savings.

## A. Anatomy (FIXED — 10 steps)

0. **Wake protocol:** pulse → flag → handoff → working docs. Locks are honored,
   not re-litigated.
1. **Contract first:** name the human gates (2–4), set token reserve (≥30%),
   declare write boundaries, commit-never-push.
2. **Mechanics down, judgment in the seat:** shell → Delta; bulk reads → Explore;
   online research → Epoch; math derivation → Color. The seat's asset is accumulated
   synthesis context — never serialize judgment into a subagent.
3. **Blind fan-out:** heterogeneous legs (online-depth / offline-math / cross-vendor),
   blind to each other. One researcher sees all forks. Each leg writes its own dated artifact.
4. **Cross-measure (the seat's own work):** convergences (independent agreement =
   strongest signal) · divergences + explicit rulings · corrections registry ·
   per-fork verdicts marked pending-gavel.
5. **Targeted follow-up only** for holes the cross-measure exposes — not general
   curiosity. Bound: one round, load-bearing questions only.
6. **Derivation-locked artifact writing:** every downstream artifact derives from
   the whole processed corpus. Never draft piecemeal from raw legs.
7. **Adversarial gate before crossing:** Janus pass. Verdict REVISE = revise
   applied same day, documented in each artifact header. Conditions become mandatory sections.
8. **Thin mount checks:** extraction by read-only agents; comparison judgment stays
   in the seat. Sibling canon honored; findings contradicting a lock go to gavel queue
   as reality deltas.
9. **Consolidated gavel queue:** one numbered list at close — everything awaiting
   the human in one place.
10. **Degrade-don't-stall:** failing legs get one bounded retry then park with
    verbatim logs. Run continues; degradation flagged in the gavel queue.

## B. Swappable parameters (fill at kickoff, gaveled)

```
goal        : one sentence, gaveled
gates       : [ named human checkpoints — typically 2–4 ]
legs        : [ { id, shape: online|offline|cross-vendor, topic, assigned-to } ]
reserve     : token floor (e.g. 0.30)
paths       : { state-file, artifact-dir, commit-policy }
delegation  : which gavels seat absorbs (with counter-sign) vs human-only
```

## C. Compatibility (vs research-pattern.md)

Sibling. Shares: blind fan-out · named gates · cross-measure · adversarial gate
(Janus ≈ refuter) · persist-to-disk · degrade-don't-stall. Differs: topology-general
(any judgment-dense run), not research-specific — no fixed lens taxonomy, no fixed
report template. Use research-pattern for deep studies with a hypothesis; use
run-synthesis for cross-measurement, derivation-locked artifacts, and mixed-corpus runs.
