# Plan

Turn the current request into an implementation plan before code is written.

## Required behavior

1. Read the nearest project `CLAUDE.md` first.
2. Identify the real goal and the constraints.
3. Inspect the minimum relevant files needed to plan safely.
4. Propose the smallest safe approach.
5. Call out risks, assumptions, and verification steps.

## Output

Provide:

1. Goal
2. Constraints
3. Proposed approach
4. Risks and open questions
5. Test or verification plan
6. Files likely to change

Do not implement yet unless the user explicitly switches from planning to execution.
