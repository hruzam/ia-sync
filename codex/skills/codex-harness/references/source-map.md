## Retrieval rules

- Start with the active project's own instructions and evidence.
- Search by concept and failure mode, not only by remembered filename.
- Prefer current portable source over deployed runtime copies.
- Label historical version claims as stale until reverified.
- When two maps disagree, report the curvature and identify which authority can resolve it.
