## 6. Recommended boundaries / proposals
- **Criterion (one axis, grounded in D1):** "A seat is germline-bound when one meaning is consumed by more than one runtime; its source is `germline/agents/<slug>/identity.md` and every consuming runtime carries a binding that declares the consumption (generated file / runtime loader / described combination). A seat is vendor-native when its meaning lives in one runtime's primitive and nothing else reads it; a same-name file on another vendor is then a declared pointer or a declared homonym, never a silent twin." Proof is a per-binding capability (stamp echo + canary on CLI vendors; stamp echo only on chatbots), not a precondition — else chatbots are excluded while README :12 already has them reading germline. Test: Houston fits; Oraculum → vendor-native ×2, must be declared; Astrobley → pointer (gaveled 2026-09-01); role TOMLs, Flight → vendor-native; chatbots → third binding, not a seat class. Alternatives: every cross-vendor seat germline-bound (forces the Oraculum one-seat decision implicitly; overhead for Astrobley); only seats with cards/proof (Houston forever; homonym unlabeled); operator's list (fine with the sentence as its reason).
- **Seam contract (derived from the Houston bindings):** MUST — wrapper path(s) + exact keys, body = loader only; capability→tool/sandbox/approval mapping; routes + entry; card selection + omission default; per-route permissions/delegation/return rows; placement; cwd fact; proof (canary prefix, entry-proof lines, fresh-witness rule) + vendor proof extras; sources; **enforcement class per route** (tools list = enforced; hooks = enforced, script + deploy path; sandbox/approval = inherited/ignored; prose = not enforced — generalizes binding.claude :49–51 and covers hooks). MAY — dated vendor facts with witness/version; the pin *rule*. MUST NOT — identity prose; card pens (point, don't restate); project paths; lock content; **the pin value**.
- **Oraculum coherence without germline-binding:** a `twin:` cross-cite line in each file naming the other path and the declared relation (`homonym: different route and pen` or `one seat: parity owed`). Rejected: shared `seat.oraculum.md` (germline-binding by another name); parity row in the model-effort card (scope is pins only); nothing (cost lands on vendor-blind text naming "Oraculum").
