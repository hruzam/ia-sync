## 4. Mismatches discovered

1. **POINT gate vs runtime reality:** "no global trust edits" cannot coexist with an interactive
   run in a fresh fixture — Claude requires trust before project/local hooks load, and its default
   answer exits. Resolved by majkee's narrow authorization + removal (field 1). Future interactive
   qualification needs either that authorization or an already-trusted disposable root.
2. **Documented vs measured:** consistent with the reference Cartan cited (non-blocking timeout
   and errors). Measured addition: the fail-open is **silent** — no stderr, no error text to the
   model, a normal success result. Also consistent: `--bare` does not read OAuth (help text).
3. **Mode:** print skips trust entirely; interactive backgrounds the child. Guard behavior identical.
4. **Instrument slips, disclosed:** my first interactive completion check matched the echoed
   prompt text and my runner's first summary was file-ambiguous — both caught before any claim;
   the local `cp` alias is interactive (`cp -i`), bypassed with `command cp -f`; evidence equality
   proven by `diff -rq` (106 files).
5. Not exercised: `Write`, `MultiEdit`, `NotebookEdit` — the model only ever used `Read`/`Edit`.
   The guard matcher covered them; their event names and behavior remain unmeasured.

## 5. Recommended next task

**Before B1, fold two B0-derived invariants into the shared muticula contract** (a contract edit,
not code): (a) **fail-closed must live inside the guard** — the runtime fails open on timeout,
crash, malformed output and missing executable, so the guard's own code must turn every internal
error into an explicit deny, stay far below its timeout, and be invoked by direct executable path
(the interpreter form turns a missing file into an accidental exit-2 block); (b) **a liveness
handshake** — a SessionStart marker registers the actor with the core; a session whose marker never
arrived (C7 `disableAllHooks`, missing layer, untrusted interactive root) is shown as *uncovered*,
never as protected. The landmine shape itself is proven: a deny with a reason the model reads.
