Only static inspection of the final frozen manifest is permitted. No runtime loading, execution,

allowed. Majkee's 2026-10-22 sample selection permits this draft correction; the mapping-method

## Ordinary controller/function structure

- **split evidenced** — citations inside the frozen source set establish all three markers:
  a controller/selection responsibility explicitly stated in source text, a function/procedure
  responsibility explicitly stated in source text, and an explicitly stated relationship by
  which the former selects, delegates to, or invokes the latter. A heading, filename, identifier,
  or role name alone does not establish a responsibility or relationship.
- **not evidenced within frozen scope** — every frozen entry has been inspected under the same
  markers and no complete three-marker set is cited. This is not a claim about files outside the
  manifest and does not close any of the seven audit inputs.
- **unresolved** — a needed source is absent or unreadable, a marker or relationship is ambiguous,
  source identity changes, or an additional source/design decision is needed. Stop rather than
  broadening the method.

## Separate question — need for exceptional composition

An ordinary split does not establish a need for a global controller paired with a project-local
function. Record this question separately from the structural result above.

- **requirement evidenced** — frozen-source citations identify a concrete task, an explicitly
  global controller/project-local function pairing, and a stated reason why the task cannot be
  satisfied by a coherent scoped package or explicit project inputs to a shared function.
  This records the cited requirement and rationale; it does not prove runtime compatibility,
  choose a C1 policy, or authorize that pairing.
- **not evidenced within frozen scope** — the inspected sources supply no such complete case.
  This is a scope-limited finding, not proof that no future task can need the exception.
- **unresolved** — the pairing, task, rationale, or required source is ambiguous or absent in a
  way that prevents assessment. Name the missing evidence or owner decision and hold.

Do not invent a requirement from source layout or design an alternative during this static
pass. A concrete real-task trial may later test the claimed need under its own authorization.
C1(a-c), composer, classmap-as-report, F-r3-2, and F-r3-4 each retain their required disposition;
neither result above alone resolves or excludes them.
