## 6. What the crawl added, and where it could mislead

**Useful output observed:** the collection was separated into living gates, finished trials awaiting disposition, closed scopes with residual obligations, evidence-only collections and superseded redirects. The A1 example was resolved from existing consolidation rather than rebuilt. Existing compressed knowledge was found, and specific navigation hazards were identified. **Failure modes exposed:**

- First-YAML-only reading misclassifies G05/G06 as awaiting acceptance. A closure block later in the file changes the interpretation.
- A directory name or number is an address, not a reliable phase/order/state marker. G07's name no longer adequately describes its later experiment role.
- A finished trial is not an accepted result; a closed setup is not closure of unrelated domain research. G09 and A2 demonstrate the distinction.
- A historical conclusion can be retained deliberately and corrected by an addendum. A9's original score prose must not override its explicit adjudication.
- A copy/hash establishes byte identity, not durable transport or recovery. Untracked evidence makes this important before pruning.
- A missing control document is not an orphan verdict. G01 is a useful evidence collection with acknowledged corrections.
- Shared names and a local addendum do not prove project attachment. Houston disclosed the actual neutral route rather than claiming a local seat it had not resolved.
- Fork rollouts repeat parent metadata. Selecting the last `session_meta` would incorrectly identify all children as the parent and blur actual model carriage.
- Parallel collection still costs integration. Scope disjointness reduced primary duplication, but common orientation and some coordinator reading overlapped; no net saving was measured.

No claim is made about completeness of all session contents, all links, all unresolved proposals, cross-host state, future re-entry reliability, or the absence of additional orphans. The crawl did not run the archived experiments or inspect every raw record. It was a bounded useful survey with explicit holes.
