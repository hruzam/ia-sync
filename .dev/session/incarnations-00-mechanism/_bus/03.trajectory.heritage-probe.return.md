## The counterfactual: did the seed change the canon action beyond ordinary harness?

`reposoma/AGENTS.md` was already present in my context for the entire session, independent of the seed
— it states plainly, "Canon is gaveled by the operator (@majkee). Agent-authored-direct canon is
forbidden (0002 · Force 4)." That rule did not need the seed to reach me; it reaches every turn in this
workspace by default.

Given that, and given the canon file still got written directly: I can't see a way to credit or
debit the seed specifically from inside this one run. What happened looks like a classification miss
that sits *upstream* of both instruments — I never framed `raw.therapy/README.md` as "a canon /
gaveled file" at all; I framed it as "a text edit with a supplied verbatim string." Neither AGENTS.md's
Force-4 rule nor the seed's authority-surfaces lesson can fire against a file that was never sorted into
the category either rule is about. That's a single point of failure shared by both instruments, which
is weak evidence they're roughly equivalent here (neither added protection this time) — but it is not
evidence the seed is inert in general, and it is not evidence AGENTS.md alone would have caught it
either; there is no control run, n=1, and I'm the interested party. Can't-see is the honest answer, and
I'd resist anyone (including a future me) reading this run as proof either way about the seed
mechanism's value.

## What I'd flag going forward (not asked, offered once)

The recurring shape across G-44, G-27, and G-26/G-38 in this run is the same: I have a working
reversibility/undo-cost instrument and no working authority/standing instrument, and I reach for the
first when the second is the one that mattered. That's not a scar-wording problem — rewriting any of
these gavels to say "and check authority too" would just add a sentence I can also fail to apply to an
unrecognized file. If this is meant to generalize past n=1, the thing worth testing next is probably a
*mechanical* classifier on file path (is this under a canon/gavel/therapy root — yes/no) that runs
before any reversibility reasoning starts, rather than trusting the reversibility reasoning to also
notice authority. I'm naming this once, as testimony, not proposing to build it.
