## S — establish semantic alignment first

Freeze the target as **conversation accounting within a declared projection**, distinct from actual implementation success. An explicit completion claim accounts for a request under this rubric even if its real-world truth is unverified. Acknowledged open/planned, deliberate deferral and supersession/cancellation also account for it. Lack of corroboration is not automatically an unanswered request.

Two independent annotators enumerate atomic actionable requests from the eligible chronology **before** seeing model output, the previous grouping or the old baseline. Save source span IDs and raw disagreements. Resolve disagreements with a third adjudicator using a frozen rubric; report agreement and unresolved cases. This is proposed annotation work, not a claim that independent human gold already exists.

For each atom record: eligibility and cutoff; requested outcome; scope changes; accounting evidence span/time; status; ambiguity; missing evidence; adjudicator/version. Use six mutually exclusive operational statuses: answered/completion-claimed, acknowledged open/planned, deliberately deferred, superseded/cancelled, genuinely unanswered, insufficient evidence. Freeze precedence before labels: a later explicit supersession changes the active request; partial completion does not dispose of an unaccounted actionable remainder; insufficient evidence is retained rather than silently called negative. Split compound requests where meaningful. Cases still genuinely ambiguous remain flagged and excluded from a single hard-label score, with exclusion counts and sensitivity bounds reported.

Only then map atoms to proposed groups and certify coverage, overlap and the aggregate domain. Referencing every message does not establish coverage of every actionable part. For the binary unanswered predicate, use three-valued propagation: TRUE if any eligible atom is known unaccounted; FALSE only if the map is exhaustive and every eligible atom is known accounted; otherwise UNKNOWN. An exhaustive empty request set has ANY=FALSE. Apply the same rule at group and conversation level. A known positive dominates another atom's unknown status; unknown must never become a negative by omission.

For **new** six-class group questions, freeze this deterministic precedence: genuinely unanswered → insufficient evidence → acknowledged open/planned → deliberately deferred → answered/completion-claimed → superseded/cancelled. Choose the first class represented among the group's atom dispositions; a coverage gap that prevents deciding unanswered triggers insufficient evidence unless a positive is already established. Thus mixed answered+superseded becomes answered, while mixed answered+open becomes open. Do not emit an empty group. This is a proposed operational aggregation convention, not a recovered provider contract or a retroactive relabelling of November 5. Embed it in the question and annotation manual before new comparisons. Preserve per-atom dispositions so that a group category does not erase accounted subparts.

Distinguish a reproducibly adjudicated **insufficient-evidence disposition** (a scoreable sixth categorical label, but unknown binary truth) from annotators' unresolved disagreement about the correct disposition (no hard gold label). Exclude the latter from hard-label scores with explicit counts/sensitivity bounds. If this aggregation convention proves unhelpful, elicit and score atomic six-class questions instead; do not score a group forecast as though it were an atom forecast.

## C — test coherence on controlled events

Minimum proposed fixture design: twelve contrast families, each with an accounted and an unaccounted counterpart, producing **24 base conversations**. Add incomplete-evidence versions with unknown labels as diagnostic fixtures, not forced binary counterparts.

| Family | Accounted counterpart (ANY=FALSE) | Unaccounted counterpart (ANY=TRUE) |
|---|---|---|
| Simple request | Answer present | Answer omitted |
| Planned work | Explicit open acknowledgement | No disposition |
| Deferral | Deliberate deferral | No disposition |
| Supersession | Explicit cancellation; replacement accounted | Original remains active and ignored; adjacent request accounted |
| Compound request | Every actionable part accounted | One actionable part omitted |
| Repeated request | Repetition of an already accounted outcome, no new demand | Repetition adds a distinct scope requirement left ignored |
| Completion claims | Explicit completion claim | No claim or other disposition; external success remains a separate target |
| Cutoff | Accounting before cutoff | Accounting only after cutoff, with complete pre-cutoff projection |
| Attachment-related request | Eligible request concerning an accessible attachment receives disposition | Same accessible attachment/request, no disposition |
| Quotation | Quoted request is merely data; all actual requests accounted | Same request becomes an actual operator demand left ignored |
| Conflicting chronology | Correction leaves an explicit revised open disposition | Later retraction explicitly leaves the prior demand unaccounted under the frozen rubric |
| Group boundary | Distributed actionable parts all accounted | One distributed part omitted, despite every message being mapped |

Inaccessible attachments, missing relevant chronology and disputed interpretations are additional UNKNOWN diagnostics outside these 24 true/false cases. Authors must adjudicate each constructed pair before using it; a difficult case that remains ambiguous moves to diagnostics and needs a replacement pair rather than a forced label. This table specifies fixture construction; the conversation texts have not yet been authored or validated.

For each base, compare original natural aggregate wording, **explicit ANY = OR(E01…En)** over a frozen exhaustive atom map, and an order/permutation variant that leaves event definitions unchanged. Group split/merge variants need a documented logical mapping and separate identifiers. The nominal 24×3=72 base variants are neither 72 independent conversations nor an authorization for 72 paid calls. Scripted finite-world fixtures can additionally encode known joint event sets to test probability arithmetic itself; these check the measurement harness, not linguistic generalization.

Preserve raw distributions. Check ranges, normalization, implied subset inequalities, complement relations where explicitly elicited, and the union bounds. If precision is documented, use interval feasibility rather than point arithmetic. Do not repair results by renormalization or substitute a product-of-complements formula without a justified independence model. Report count, magnitude and fixture families of violations. A separate consistency layer would be a later intervention with its own held-out utility test.

Passing these necessary screens is not a proof of global joint coherence. For a finite-world fixture with a complete specified event algebra, a stronger check asks whether nonnegative world masses summing to one can satisfy **all** elicited event probabilities (or documented precision intervals). Record feasibility, solver tolerances and the specified world model if this check is implemented. Do not imply that union bounds alone settle all constraints among overlapping events.

## K — measure calibration against independent outcomes

Freeze prompt/model/rubric after development. Partition **whole independent conversations and related families**, never their individual groups, variants or repeated calls, into development, optional calibrator-fitting and final test sets. Keep near duplicates, paraphrases, shared templates, actors/tasks and synthetic generator families together where they create dependence. Record split assignments before fitting or final evaluation. Real deployment-like conversations and synthetic stress cases receive separate result tables. A variant is a robustness observation nested inside its conversation.

Measure separately:

- ANY binary Brier loss `(p-y)^2` and log loss `-[y log p+(1-y)log(1-p)]`.
- Group categorical Brier loss `sum_k (p_k-y_k)^2` (this convention ranges 0–2) and log loss `-log p_true`; confusion and class-specific recall/false alarms.
- Reliability plots with bin definitions, counts and uncertainty; inspect the unanswered class as well as top-label confidence. A single ECE value is insufficient to characterize full-distribution calibration.
- Failure, refusal, missingness and abstention rates alongside coverage; ambiguity/exclusion rates with worst/best-case sensitivity. Never drop failed calls from the denominator silently.

Proper scores reward probabilistic predictions against realized outcomes; they do not by themselves isolate calibration from resolution. [Gneiting and Raftery, 2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf). Multiclass calibration has distinct interpretations; retain full vectors and specify which property is measured. [Vaicenavicius et al., 2019](https://proceedings.mlr.press/v89/vaicenavicius19a.html).

If a true outcome receives exactly zero probability, the raw log loss is infinite. Record that event. An additional clipped score may use a preregistered epsilon, explicitly labelled; it must not overwrite the raw result. Keep provider `confidence` separate from category probabilities, including when it differs from their maximum. Its name alone does not establish a correctness probability.

Use equal conversation weighting as the primary aggregate: average eligible group losses within a conversation, then across conversations. Hold the grouping convention fixed for that estimand; report split/merge variants separately. An atom-level score requires separately elicited atom-level probabilities and adjudicated atomic labels; never reuse a group probability as an atom probability. For uncertainty, resample independent conversation/family clusters, retaining paired variants. With few clusters or rare positives, wide intervals are a result, not a reason to treat individual groups as independent observations.

Choose sample size from a declared primary quantity and precision. Planning examples, **not sufficient sample sizes for calibration as a whole**:

- A simple independent Bernoulli rate needs approximately 385 observations for a worst-case normal-approximation 95% margin of ±.05. This is one rate, not 385 observations per calibration bin or proof that rare positive errors are measured well.
- With zero misses in n independent positive conversations, the exact one-sided 95% binomial upper bound on miss rate is `1 - .05^(1/n)`. At n=59 it is about .0495. This requires the sampling/independence model and a frozen decision rule; a clustered or selected sample needs different treatment.
- At 10% positive prevalence, obtaining 59 positives takes about 590 screened conversations in expectation, not a guarantee. Deliberate positive enrichment can estimate sensitivity within its sampling strata, but cannot be treated as natural deployment prevalence or unconditional calibration without appropriate design weighting.

Make prevalence and available labels explicit before choosing a budget; do not invent a convenient final N. Calibration transformations require their own fitting split. Temperature scaling is an established candidate in other settings, not a demonstrated Jev remedy. Its published success does not supply unrounded Jev logits or justify taking logs of rounded served probabilities and pretending they are native logits. [Guo et al., 2017](https://proceedings.mlr.press/v70/guo17a.html).

## U — test whether decisions improve

Freeze a deterministic checklist/lexical comparator and, if useful, a separately fixed agent baseline. Score both on the same final conversations. Do not fabricate probability forecasts for a comparator that only returns labels; compare its decision utility directly. Declare review/abstention policy and threshold from development data only, with explicit costs for missed requests, false alarms and human review.

Measure missed actionable requests, conversation-level misses, false alarms, human review minutes, completion of review, abstention/coverage, wall latency and total inference/retry/annotation/review cost. Compare at matched false-alarm or review budgets, not only the most favorable threshold for each test result. Use paired conversation-level differences with uncertainty. For human review time, counterbalance/order-randomize cases and avoid showing the same reviewer an already learned case in both arms without accounting for carryover.

## Required record and release decisions

Retain source identity/hash, source speakers separately from recorder/requester, cutoff and inclusion/exclusion rules, missingness/attachments, exact atomic and grouped question versions, evidence spans, split/family IDs, model requested/resolved IDs, raw request/reply hashes, all distributions and raw confidence, output precision/unknown precision, schema/transport errors, retries, latency/cost, annotator/adjudication versions and later labels. Store derived scores as versioned measurements referencing immutable input occurrences. Overlapping transcript snapshots must not silently count one source event twice. Private source bodies stay in their authorized custody.

| Finding | Justified next implementation |
|---|---|
| Scope/group coverage differs | Repair extraction/rubric/mapping; repeat S before interpreting probabilistic differences |
| Explicit union constraints fail | Preserve and flag incoherence; investigate question framing/aggregation; no silent probability repair |
| Semantics and the listed coherence screens pass but held-out calibration fails | Study a separately fitted transformation with untouched test data; no production fit yet |
| Calibration is acceptable but utility does not improve | Retain the simpler comparator; no claim that calibrated means useful |
| Utility improves with adequate precision and coverage | Builder may propose a bounded pilot under the actual execution/approval rules |
| Hash/schema/label leakage or missing source coverage invalidates the target | Stop interpretation/fitting, preserve failed evidence and repair the evaluation contract |

Numerical score tolerances, acceptable miss cost and deployment risk belong to the chosen application. Freeze them before final testing; this research protocol does not invent a universal acceptance threshold. The first buildable deliverable is the offline fixture/annotation/measurement schema. The present single conversation establishes neither population calibration nor independent accuracy nor utility.
