## curvature

Malformed-fragment recovery cannot prove the fragment was not a corrupted final attempt or
settlement. It therefore retains `UNKNOWN_FRAGMENT` as a blocking spending liability while
restoring local history operations; LF-only recovery adds no liability. This conservative
choice implements BUILD's rule against erasing unknown charges or resending after recovery.

USD input is bounded to 18 integer and 18 fractional digits; arithmetic has 96-digit precision.
Provider costs outside this exact supported range retain raw evidence and remain unknown,
never silently rounded or manufactured as zero. A two-second bounded lock wait reports busy.

A final narrow review found that JSON-escaped credential echoes could decode into retained
metadata. Cartan released the bounded fix: check both raw bytes and canonical decoded JSON
strings/keys before persistence. The new mocked regression passes; rejected echoes leave
a generic unknown liability with no credential in ledger/output. This protects the actual
JSON decoding path and does not claim universal redaction of arbitrary encodings.
