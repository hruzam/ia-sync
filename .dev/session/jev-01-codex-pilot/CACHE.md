   billing downloader, limited key or live proof. State those gaps precisely; close T03 before
   treating provider spend as inspectable through Jev.

   request ID mean different things. `hlm` is requester identity, not a CLI brand or proof of
   authorization. Preserve both producing and consuming provenance through reuse.
3. **Channel scope:** current code accepts only `main`. Earlier “defaults to main” wording could
   imply other channels work. They do not yet; CLI ID does not create a new allowance/channel.
4. **Immutable policy trap:** opening with UNSET model/budget cannot later be edited by today's
   commands. Use temporary beds for offline tests; never create an arbitrary real engagement or
   a replacement bed merely to reset spend. Policy maintenance needs an explicit revision design.
5. **Provider facts versus local limits:** a probability/confidence is not calibration; local
   admission is not a verified remote ceiling; a key reset period is not its expiry date.
6. **Recovery is evidence preservation:** malformed-tail repair retains UNKNOWN_FRAGMENT
   liability and may make forensic history non-strict JSONL. Never clear unknown remote spend
   from aggregate billing differences or resubmit automatically.
7. **Reuse is not a fresh observation:** preserve original reply event ID/provenance; a future
   cache has an index/reference role. Never manufacture consistency by replaying cached answers
   as independent experimental draws.
8. **Local custody and source control:** multiple foreign dirty files are active. Scope writes
   and deployments; no broad deploy/commit. Source changes after Nov4 need fresh hash evidence.
9. **Practical work over ceremony:** majkee delegated routine engineering judgment. Do the
   reversible work and technical review; do not repeatedly ask him to arbitrate ordinary choices.
10. **Child origin ambiguity:** the provenance implementer observed unequal CODEX_THREAD_ID
    and CODEX_SESSION_ID in its child runtime. Explicit --cli/--cli-session resolves the intended
    origin; automatic detection refuses conflicting values. Test with controlled origins and
    actual parent environment separately. Never silently choose an ambiguous caller identity.

11. **Dogfeed the permissions too:** the original operator-only interface could not run the
    requested agent audit. Get the actual bounded authority once, implement a native scoped
    path and verify it; never use test seams or clear agent environment variables to bypass it.
12. **Aggregate probability is separately elicited:** this run reports global0.15 and summed
    group-unanswered0.03. If groups exhaust the same predicate, these are not jointly coherent.
    Preserve the discrepancy; do not equate valid JSON with calibrated probability or derive
