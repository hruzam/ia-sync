## One concrete program example — paper assignment, not a dispatch

Question: which of a named set of session identities still has living work, and
what surviving obligation or evidence prevents unqualified retirement?

The controller first checks the existing registry and current owner records. For
a few known sources it reads directly. If the remaining collection warrants helpers,
it assigns disjoint primary source sets with a shared question, explicit carriage,
allowed roots, finite read/expansion budget and stop condition. No worker gains
acceptance, write, lifecycle or pruning authority. The numerical budget is selected
for that actual corpus; this paper example does not authorize calls.

Each return gives: full identity; governing disposition and owner; unresolved
obligation; evidence/correction chain; custody status; anomaly; inspected/uninspected
coverage. The controller checks the consequential citations and resolves disagreements
before proposing action. The operator's later cleanup grant is a separate event.

Success is a correct, source-backed map that makes the decision reviewable. Economy
requires its own measured comparison. A partial but well-attributed anomaly return can
still be useful; a neat unsupported classification is not completion.
