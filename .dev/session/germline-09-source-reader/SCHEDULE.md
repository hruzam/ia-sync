## Measurement and exception handling

Caretaker logs selected operation events and capsule byte counts to `raw/caretaker/metrics/`.
Cartan records main source opens/decision requests/operational rescues as small event facts;
do not manufacture native token counts. Evidence files are past observations, not a second
current-position authority. Every yield has one STATUS next/expected action.

Native child unavailable after a root restart: do not assume old memory/handle survives. Use
STATUS plus pinned program and existing receipts to reconstruct one replacement caretaker;
reconcile IDs before any new ask. Record the replacement as an intervention. An unknown
remote outcome remains a hold, even if native worker replacement succeeds.
