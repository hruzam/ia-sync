No mechanism, registry or dispatcher is warranted (HANDSHAKE :35 "by the existing house mechanism"; identity :115 "ceremony is earned by evidence"; AGENTS.md bias; myShell §1.6 "no second dispatcher/registry"). ## 6. Recommended boundaries / proposals
- **Ownership per piece (U2 §6):** proof block = bootstrap (wrapper + README :10–11 for the stamp rule; bindings carry only vendor extras `cwd`, `selected:`); kind line = identity §Return contract, with position added ("the first line after the proof block"); body = card. - **Minimal complete prescription (Houston, any card, any vendor):** `Route: … (canary: …)` / `<abs path> · stamp: <tok>[ · cwd: …][ · selected: …]` per file in load order / `card: <card> · verdict: <value>` / body as the card prescribes.
- **Bus/consult boundary sentence (owner: consult §Writes, after :33):** "A POINT addressed to me under consult is answered in the invoker's context, never as `_bus/NN.houston.return.md` — I am never a bus seat under this card; the head's own RETURN cites `raw/consult.<topic>.<date>.md` (or quotes my proof block and kind line verbatim) as its evidence. Under audit or sitting a `_bus/` landing is possible only when the invocation assigns it, and then takes the bus GUIDE's six headings." Audit :26–27 gets the half-clause pointing at the six headings (the only GUIDE pointer needed from germline).
- **Delivery sentence, germline-wide (README beside the one-witness rule — U6 D13 destination):** "A return is delivered when the consumer's first act on disk quotes its proof block and kind line verbatim; a record that relays a return without them is a relay, not evidence, and does not close the exchange." myShell's available/delivered/consumed stay vocabulary, not tracked states. Alternatives rejected: `consumed-by:` on every return (inline tool returns have no file); a receipt ledger (bias; myShell); nothing (G01 cost).
- **One header grammar, RETURN side only (Majkee's parser direction; names what the house already does):** `header := [route-line] proof-line+ kind-line`; `proof := <abs path> · stamp: <8hex>[ · <key>: <value>]*`; `kind := <kind-key>: <value>[ · <key>: <value>]*` — exactly one line, first after the proof block; `body := free text`. Parser contract without a parser: split a line on ` · `, each field on the first `: `; ` · ` survives paste into shell, YAML and Markdown (Epoch's constraint; `&` does not). Instances: Houston `card: consult · verdict: stretches` (position fixed, content unchanged); programs `<controller abs path> · stamp: <tok>` / `<fn abs path> · stamp: <tok> · expected: <tok>` (the table check made visible — U3 §6) then `fn: carry-unfinished · result: report | pair | incomplete-pair`; saddle `fn: saddle-project · result: READY` (moves the bare first token into a value — Majkee's corner; alternative: leave bare, two first tokens). Leaves unchanged: Route line, stamp lines, `out of card:` (already a kind line), `CARRIED TO/FROM` (journal receipt, not a return header), bus YAML, mail filename, body tags. Does not touch invocation lines (`fn:` echoes the invoked name; C1 stays with Cartan).
- **Neutral Houston / unassigned audit landing (owner: audit :26–27; identity :144 cites):** "No addendum → the landing path is the one the invocation assigns, inside the invoking session's bed; neither assigned nor addendum-named → the reply is the landing: findings return inline, I open with `out of card: landing unassigned → invoker`, and write nothing." Consult and sitting unaffected. Rejected: a global default dir (a landing registry).
