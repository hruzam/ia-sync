## Claude Code instruction and hook comparison — documented

Sources: [Claude memory](https://code.claude.com/docs/en/memory),
[Claude hooks reference](https://code.claude.com/docs/en/hooks).

- Claude expands `@path` inside CLAUDE.md, relative to the containing file, including
  recursive imports up to four hops. Thus adjacent `@AGENTS.md` imports its contents.
- Current Claude documentation (not an observed local version or configuration) also
  describes native AGENTS.md support: default
  `claude-md-or-agents-md` selects AGENTS.md only when no relevant CLAUDE.md is in
  cwd or ancestors. A setting can load both; an imported file is not loaded twice.
  The lab CLAUDE.md import is a declared path, not a witness of an installed session.
- AGENTS.md native support is version/plugin dependent; versions before 2.1.277 and
  disabled built-in plugin sessions lack it. Do not assume the installed version.
- Claude's direct AGENTS.md reader does not read `AGENTS.override.md`; its imported
  AGENTS.md and directly discovered AGENTS.md differ in InstructionsLoaded hook firing.
- Hooks are separately configured lifecycle actions with event-specific decisions;
  a markdown import does not port Claude hook behavior into Codex.
- Imported text is instruction context, not independent evidence of execution.

## Child model selection and permissions

  and effort, `[agents]` defaults, or inherited parent settings can select a helper.

  parent. If explicit/default model lacks a supplied/default effort, model default
  effort applies. A custom role's `model` and `model_reasoning_effort` take precedence
  over those resolved values, including explicit spawn values.

## Claude subagents: comparison only

Source: [Claude Code custom subagents](https://code.claude.com/docs/en/sub-agents).

- Claude subagents have their own context and configurable tool lists, permissions,
  model and hooks; the parent may delegate based on descriptions or direct request.

  `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` controlling depth; omit/disallow `Agent`
