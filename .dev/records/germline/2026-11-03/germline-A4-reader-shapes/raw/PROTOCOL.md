# A4 preregistered pilot protocol

Frozen before any subject dispatch. Question: does conventional structured layout
help apply the same explicit facts compared with ordinary prose? It does not isolate
training-data familiarity, ontology choice, registry navigation or actual crawling.

Four fresh subjects with fork_turns=none; each sees one packet once, with all three
scenarios in S1/S2/S3 order. Cells: cycle 02 Terra structured; 03 Luna prose;
04 Terra prose; 05 Luna structured. Both requested low effort. At most two concurrent.
The shared prompt wrapper is identical; only the packet layout differs. Both arms
contain the exact same clauses, order, IDs and questions. Structured uses a two-column
fact table and Facts/Question headings; prose uses paragraphs. No answer-bearing
interpretive headings. Prompt length is measured and is a layout overhead confound.

No crossover: Astrobley's suggestion to counterbalance repeated exposure is not used
because each of four DIFFERENT subjects receives only one arm. There are four
independent requested contexts, not eight trials and not twelve independent subjects.
No subject sees parent history, rubric, protocol, another return or feedback.

Score RUBRIC.json: 12 binary items per subject, semantic support quoted. Preserve
all raw returns; missing return is a missing observation, not an invented failure
answer. Unsupported extras and authority violations are separate observations.
No changes to questions, criteria or weights after dispatch. No retries/corrections.

Requested model/effort, returned task handle and arrival timestamp are observed
routing evidence. Actual backend model/effort and tool traces remain unverified
unless separately exposed. The no-tools boundary is an instruction, not a claimed
technical sandbox. Self-report does not independently attest its enforcement.
Prompt/response words and bytes are observable; exact token/price/compute counts are
unknown without telemetry. Arrival latency includes scheduling/parent observation;
do not rank model speed from it. No cost-saving or general reliability conclusion.

Head verifies each subject answer against frozen facts, preserving anomalies.
A ceiling result indicates an easy fixture or adequate performance in both arms;
it does not prove equivalent general capability. A difference is a lead, not a
causal effect. RESULT.md must state next discriminating experiment without launching
more subjects. A3 receives a pointer; its own acceptance remains separate.
