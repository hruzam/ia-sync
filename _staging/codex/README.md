# Cartan's Codex observation bed

Tracked, deploy-inert space for Codex observations, probes, receipts, and candidate
primitives. Nothing under this directory is copied to a live Codex home.

Use provenance-first names such as:

```text
cartan.observation.<topic>.<YYYY-MM-DD>.md
cartan.probe.<topic>.<YYYY-MM-DD>.md
cartan.candidate.<topic>.<YYYY-MM-DD>.md
```

An observation records evidence and open questions; it does not silently become policy.
Promote by meaning:

- volatile platform fact -> `reposoma/raw.settings/`
- durable builder/user guidance -> the appropriate shared guide
- deployable Codex behavior -> `ia-sync/codex/`
- experimental cross-agent mechanism -> the relevant Nablarva task bed

Do not place credentials, raw session histories, database copies, caches, or unreviewed
runtime dumps here.
