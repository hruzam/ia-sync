# Example receipt reconciliation

Draft template. The header uses the familiar two-field skill shape. This file is
outside skill discovery directories and is not installed or runtime-qualified.

## Scope

Use for inspecting an assigned task receipt. The invoking assignment and project rules
supply the actual authority and file scope.

## When to use

Use when an operation returned uncertain output, an interrupted turn, or missing identity.

## Inputs

- The exact assigned receipt and its recorded output paths.
- The governing task contract and recovery instructions.

## Contract

Inspect the named evidence. Distinguish a running operation from an uncertain submission.
Return observed state, evidence, blocker and one next action. Follow the governing recovery
instructions before any further operation.

## Outputs

A compact finding and exact evidence pointers.
